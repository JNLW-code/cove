Cove
====

A menu-bar app that turns the MacBook notch into a Dynamic Island for Claude Code:
your sessions, Allow / Deny for permission requests, Claude's questions and plans,
a reply box, plus a Launchpad (Cmd+4), Spotify / Apple Music, weather, calendar
and quick controls. Nothing leaves the Mac except the weather request (Open-Meteo)
and album art (Spotify's own image server).

You need
--------
- A MacBook with a notch, Apple silicon, macOS 26 or later.
- Claude Code 2.1.288 or later (the desktop app or the command-line tool), run at
  least once so that ~/.claude exists.

Install
-------
1. Drag Cove into Applications.
2. Open Cove. macOS will refuse the first time: it says the app could not be
   verified. That is because Cove is signed with its maker's own certificate, not
   an Apple Developer ID. Go to System Settings > Privacy & Security, scroll down
   to the message about Cove and click "Open Anyway", then open Cove again.
   You only do this once.
3. Double-click "Install Hooks.command". If macOS refuses it the same way,
   right-click it and choose Open. It copies two small files into
   ~/.claude/island and opens a snippet in TextEdit.
4. Paste the snippet's entries into ~/.claude/settings.json inside the "hooks"
   object (create "hooks": { } if the file has none). If you already have hooks
   for SessionStart or PostToolUse, add Cove's entries to those arrays rather
   than replacing them. Claude Code reads the change by itself.
5. Start a Claude Code session in a trusted folder. Rest the mouse on the notch.

Permissions Cove asks for, each only when first needed
-------------------------------------------------------
- Calendar: the next-event tile.
- Automation for Spotify, Apple Music, System Events: play / pause / artwork and
  the dark-mode button.
- Accessibility: typing a reply into the Claude app when its hook has moved on.
- Full Disk Access (optional, never prompted): the Do Not Disturb peek. See
  Cove's menu > Permissions.

Remove
------
Quit Cove, delete it from Applications, delete ~/.claude/island and
~/Library/Application Support/Cove, and remove the hook entries whose command
contains ".claude/island/hook.sh" from ~/.claude/settings.json.
